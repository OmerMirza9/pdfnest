    Pull out just the pages you need

    Sometimes you only need a few pages from a long document — a single chapter, one signed page, or a range to send to a colleague. PDFNest's split tool lets you type exactly which pages to keep using a familiar format like 1-3, 5, 8-10, and builds a fresh PDF with only those pages.

    Need every page as its own file? Switch to “Split every page” and PDFNest bundles each page into a separate PDF inside a single ZIP download. As always, your document is processed on your device and never uploaded.

    Split PDF — FAQ

    How do I write page ranges?

    Separate pages with commas and use a dash for ranges, e.g. 1-3, 5, 8-10 keeps pages 1, 2, 3, 5, 8, 9 and 10.

    Can I split every page into its own file?

    Yes. Choose “Split every page” and you'll get a ZIP containing one PDF per page.

    Is the original file changed?

    No. Your original stays untouched — the tool creates new files for you to download.
