How to Zip Files on iPhone and Android

PBy the PDFNest Team·October 3, 2026·5 min read

Zipping on a phone is mostly a problem of finding the files, not compressing them. Both iOS and Android can build an archive without any app, and a mobile browser can do it too — but the files you want are often scattered between Photos, Downloads and a messaging app. Gather them first, then choose whichever of the three routes below fits.

Gather the files into one place first

On a phone, the files you want to send rarely live together. Photos sit in the photo library, email attachments sit inside the mail app, downloads sit in a browser folder, and anything from a messaging app may only exist inside that app. Zipping cannot reach across those boundaries, so the first job is collecting everything into one folder.

Create a folder in the Files app on iOS, or in your file manager on Android, named for what you are sending. Save or share each item into it: use the share action from Photos, the save-to-Files action from Mail, and the move action from your downloads folder. It feels like extra work, and it is the step that makes the rest straightforward.

Check what you are actually sending while you do this. Photos taken on a modern phone are large, and twenty of them will exceed most email limits before any archive is built. If size is the reason you are zipping, compress the images first with Compress Image — that reduces the total far more than ZIP will.

Zip files on iPhone and iPad with the Files app

Open the Files app and navigate to the folder holding your items. Tap Select, choose the files you want, then use the more-actions menu and pick Compress. iOS writes a .zip into the same folder. Selecting a single folder and compressing it archives the whole folder with its structure.

The archive is named after the file when you compress one item, and Archive.zip when you compress several. Rename it to something meaningful straight away — long-press the archive and choose Rename. A dozen files called Archive.zip in a recipient’s inbox is a predictable and avoidable annoyance.

Tapping the finished archive extracts it again rather than opening a preview, which is handy for checking your own work: extract it in a different folder and confirm the contents are what you intended. iOS adds a number rather than overwriting when a folder of that name already exists, so repeated checks quietly accumulate folders worth tidying up.

Zip files on Android

Android’s built-in Files app handles this, as do the file managers that device makers ship. Open the folder, long-press the first file to enter selection mode, tap the rest, then look for Compress or Zip in the menu. The archive is written into the current folder.

The exact wording and menu position vary between manufacturers more than on iOS — Samsung, Google and others each arrange it slightly differently, and the action occasionally sits behind the three-dot menu rather than on the main bar. If you cannot find it, the browser route in the next section works identically on every Android device.

Watch where your files actually are. Android apps often keep their own storage areas, and a file visible inside a messaging app may need to be saved to Downloads before a file manager can see it. If a file does not appear in the file manager, that is why — share it to Downloads first.

Use a mobile browser instead

Open Create ZIP in your phone’s browser and tap to pick files. The file picker lets you choose from Files, Photos or Downloads depending on your device, so it can sometimes reach things a single file manager cannot. Pick the compression level, name the archive and download it.

The appeal is control and consistency: you get the same four compression levels and a before-and-after size, which the built-in tools do not show, and the steps are identical on both platforms. The archive is assembled in your browser — nothing is uploaded — so a folder of personal documents never leaves the phone.

One genuine limitation: the whole-folder option is a desktop browser feature and does not work reliably on phones. On mobile, select the files individually, or use the Files app for a folder. If structure matters and you have many nested folders, that is a sign to do this part on a computer.

Mobile limits worth knowing

Memory is the real constraint. Building an archive means holding the contents while the file is assembled, and a phone browser has far less headroom than a desktop. A few dozen documents are fine; several hundred photos or a couple of video files may stall or fail outright. That is a device limit, not a fault in the file.

Compression will not help with the file types phones produce most. Photos and videos are already compressed, so a ZIP of twenty photos is about the size of twenty photos. Zipping them is still worth doing to send one attachment instead of twenty, but do not expect the total to shrink — see choosing a compression level for which contents actually benefit.

Encryption is not available in the browser. If the archive genuinely needs a password, build it on a computer with an archive tool that supports encryption, or protect the documents themselves — Protect PDF adds a password to a PDF, which is often what was actually needed.

Check the archive, then share it

Open your own archive before sending it. On iOS, tap it to extract into a test folder; on Android, extract it from the file manager; in a browser, drop it into Unzip to list the contents. Confirm the file count matches what you selected — a missed tap in a selection list is easy to make and invisible afterwards.

Note where the archive was saved. The Files app writes it beside the originals, but a browser saves it to your downloads location, which is a different folder from the one you picked files from. People most often conclude the zipping failed when the archive is simply sitting somewhere else.

Then share it from the file’s own share action rather than re-attaching from inside an app. Mention the file count in your message so the recipient can check it against what arrives, and if the archive is still too large for email, the large-attachment guide covers the alternatives.

Frequently asked questions

Do I need an app to zip files on a phone?

No. The Files app on iPhone and iPad and the file manager on Android both create ZIP archives, and a mobile browser tool works without installing anything.

Can I zip a whole folder from a phone browser?

Not reliably. The folder picker a browser tool uses is a desktop feature. On a phone, select the files individually, or use the built-in Files app to compress a folder.

Where does the ZIP file go on my phone?

The Files app saves it beside the originals. A browser tool saves it to your downloads location, which is a different folder from the one you picked the files from.
