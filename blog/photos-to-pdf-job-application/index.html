Combine Photos into a PDF for a Job Application

PBy the PDFNest Team·September 11, 2026·5 min read

An application form asks for one PDF, but your supporting documents are photographs on your phone. You can combine those photos into a single file without pasting them into a word processor. The important part is preparing readable pages in the right order before you submit.

Check what the application actually asks for

Start with the instructions beside the attachment field. Note the accepted file type, maximum size, required documents and whether the employer wants one combined attachment or separate files. A field labelled “CV” should not automatically receive every certificate you own. Prepare only the documents requested for that field.

Write a short page checklist before converting anything. For example, a supporting-documents attachment might need a qualification certificate followed by two training records. If the instructions specify a sequence, use it. If they do not, group related documents and keep the pages of each document together. Do not add identity documents unless they are requested.

Keep your CV in its original exported PDF when possible. Photographing an existing digital document makes it harder to read and removes the benefit of selectable text. This workflow is for documents you have as photos; you can combine them with an existing PDF later if the application requires it.

Prepare clear photos before making the PDF

Place each sheet on a flat surface in even light. Hold the camera parallel to the paper, include all four corners and check that your hand does not cast a shadow over the writing. A sharp photograph is more useful than a large photograph with motion blur. Open each image and inspect the smallest text before moving on.

Remove unnecessary background with the Crop Image tool, leaving a small border so no text or stamps are cut off. Correct sideways pages with Rotate Image. Cropping is not perspective correction: if the paper looks strongly trapezoidal, retaking the photo is usually the cleaner starting point.

Use JPG or PNG files for this workflow. If a phone photo format will not open, export a JPG copy from your photo app first. Rename the prepared files with an obvious sequence such as 01-certificate.jpg and 02-training.jpg. The names help you check the order, but still verify the list inside the converter.

Combine the photos with PDFNest

  1. Open JPG to PDF and select your prepared images.
  2. Drag the files into the required order. Each image becomes one PDF page.
  3. Choose a page size. Use A4 or US Letter if the instructions request a standard size. Fit to image follows each image’s proportions instead.
  4. Choose the orientation and margin. Preview the downloaded result if your set mixes portrait and landscape documents.
  5. Select Convert to PDF, then Download PDF.

The tool fits each image inside the chosen page while keeping its proportions. A wide photograph on a portrait page can therefore have considerable empty space. Rotating the photo or using a landscape page may improve readability; stretching the writing to fill the page would not.

JPG and PNG images are embedded without an additional image re-encoding step in this converter. That preserves the detail already in those files, but it cannot sharpen an out-of-focus original. Changing the PDF page size alone is also not a reliable way to make a large image file smaller.

Add an existing CV only when one attachment is required

If the employer explicitly asks for a single packet containing your CV and supporting documents, first create the photo PDF. Then open Merge PDF, add the existing CV PDF and your new supporting-document PDF, and arrange the files in the requested order. Download the combined result and count its pages.

For example, a two-page CV plus a three-page supporting PDF should produce five pages. A different count is a useful signal to look for a missing upload or a duplicate. Merging orders whole files; if you need to move one page within the result, use Organize PDF afterwards.

Leave separate upload fields separate. Combining documents can be convenient for you while making the application harder to process if the employer expects a CV, cover letter and supporting evidence in different places.

Check file size without sacrificing readability

Compare the downloaded file’s size with the limit shown on the actual application form. There is no universal job-application PDF limit. If your file is too large, first remove accidental duplicate images and crop oversized backgrounds in the source photos, then rebuild the PDF.

For a packet consisting only of scanned or photographed pages, Compress PDF may help. Start with Light and inspect the result. PDFNest’s compressor rebuilds every page as an image at all settings, including Light. It does not preserve selectable text, working links or interactive fields. Avoid compressing a text-based CV with this tool when those features matter.

If you need both a text CV and smaller photo attachments in one file, compress the photo PDF separately, inspect it, and then merge it with the original CV. This keeps the CV out of the image-based compression step. Always compare the final file with the application requirements before submitting.

Review the exact file you will submit

Open the final download rather than trusting the intermediate previews. Check the first and last page, the page order, names, dates, certificate numbers and small print. Inspect any barcode or QR code at a useful viewing size. A document that is technically under the size limit can still be unreadable.

Give the attachment a clear filename, such as Alex-Taylor-Supporting-Documents.pdf, unless the application specifies a naming convention. Keep your originals and final PDF in separate places so that you do not accidentally attach an earlier draft.

Frequently asked questions

Can I combine JPG and PNG photos in one PDF?

Yes. Add both to JPG to PDF, arrange the files and convert. Each image becomes one page.

Will the writing become selectable text?

No. Converting photos into a PDF places the images on PDF pages; it does not run OCR or turn the writing into editable text.

Should I compress my CV together with the photos?

Avoid image-based compression when you need selectable CV text. Compress the photo PDF separately, then merge it with the original CV if one combined attachment is required.
